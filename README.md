# Retail Sales Data Cleaning and EDA

## Project Overview
This project focuses on cleaning and analyzing retail sales data using Python. The goal is to understand sales performance, profitability, discount patterns, and delivery performance.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning
- Checked missing values and duplicate records
- Standardized text values
- Converted dates and numeric columns
- Checked invalid values
- Calculated estimated revenue, cost, and profit

## Exploratory Data Analysis
- Overall revenue and profit
- Category-wise performance
- Region-wise performance
- Sales channel analysis
- Discount analysis
- Order status analysis
- Delivery time analysis
- Top products by revenue
- Correlation analysis

## Files
- `Retail_Sales_EDA.ipynb` — complete Python analysis
- `sales_raw.csv` — original synthetic dataset
- `sales_cleaned.csv` — cleaned dataset
